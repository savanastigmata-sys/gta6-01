Crescent Bay — an original open-world crime game: explore a small living city on foot and by car, steal cars, outrun the Crescent Bay PD under a 3-star wanted level, and run three story missions as Jax, from your first stolen wheels to a harbour delivery and a full-heat getaway. Traffic, pedestrians, traffic lights, a minimap, HUD, start screen and autosave included. All art, names, story and sound are original; nothing is taken from any commercial game.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open game/index.html directly in desktop Chrome. No build step, no network requests, no external assets.
